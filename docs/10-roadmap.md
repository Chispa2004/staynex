# Roadmap

Audit date: 2026-07-15

## Short Term

- Connect real Ubikos API once official documentation, sandbox and credentials are confirmed.
- Validate with one demo hotel.
- Send only to an internal test number first.
- Validate WhatsApp onboarding per hotel.
- Validate folio data quality for Pre-checkout Folio Reminder.
- Run first hotel pilot.
- Strengthen Command Center for hotel direction and operations teams.
- Confirm provider workflows with real providers and real response SLAs.

## Medium Term

- Build a PMS Orchestrator layer above individual adapters.
- Add a second confirmed PMS integration.
- Explore embedded PMS surfaces:
  - widget;
  - iframe-like panel;
  - custom module;
  - deep link with hotel/reservation context.
- Build a corporate multi-hotel command center.
- Expand observability for pilot hotels.
- Improve provider response tracking and retry workflows.
- Improve data quality validation from live PMS feeds.

## Long Term

- Full multi-PMS integration strategy.
- Enterprise-grade PMS embedded widgets.
- Larger marketplace of providers and hotel services.
- Corporate operations product for groups/chains.
- Advanced revenue intelligence.
- Multi-property guest intelligence.
- Enterprise audit/compliance workflows.
- Advanced BI exports and warehouse integrations.

## Not Current Claims

The following should be described as roadmap or pending:

- live Ubikos integration;
- complete PMS Orchestrator;
- universal multi-PMS support;
- embedded PMS widgets;
- fully automated production guest messaging at scale;
- validated enterprise deployment across hotel groups.
